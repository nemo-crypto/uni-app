# MUI 心理测评与任务页面示例

当前目录包含基于HTML、jQuery和MUI的登录、任务、测评、统计及雷达图页面。虽然原README标为uni-app，但现有入口与资源属于静态/H5应用结构，没有uni-app源码清单或Node构建配置。

## 目录与功能

| 路径 | 说明 |
|---|---|
| [login.html](login.html) | manifest声明的应用启动页面 |
| [index.html](index.html) | 首页与任务相关入口 |
| `task_1/` | 任务页面资源 |
| `radar.html`、`radar2.html` | 雷达图展示 |
| `WebContent/experiments/` | 视觉、记忆等实验页面 |
| `WebContent/js/` | 统计、图表和业务交互代码 |
| `js/`、`css/` | MUI、公共逻辑及基础样式 |
| `manifest.json` | H5 App打包配置，包含非标准JSON扩展 |

## 预览与设备运行

普通Web页面可通过本机静态服务查看：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8080/login.html`，再根据业务流程进入任务页面。目录没有package.json，不应执行npm脚手架命令。

依赖H5+能力的页面需要相应App运行容器；仅在桌面浏览器预览不能验证原生桥接和设备行为。打包前核对manifest、图标、权限与实际使用的开发工具。

## 接口与数据依赖

登录、任务及实验记录可能调用历史业务服务。接入时先检查 `js/common.js` 及相应页面的请求地址、登录数据和参数，不要把静态页面可打开视为业务已恢复。

当前没有配套服务端、数据库迁移或自动化测试命令；unpackage等目录属于历史打包资源，开发说明以源页面为准。

## 维护与验收

通用逻辑放公共脚本，实验页面保持各自入口与资源路径。分别检查页面加载、登录/任务接口、实验结果保存、雷达图和设备能力。本轮只做源码与文档检查，没有连接历史业务后端或采集用户测评数据。
